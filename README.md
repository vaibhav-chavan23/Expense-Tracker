# Expense Tracker – MERN Stack Application

A modern full-stack Expense Tracker web application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
The application helps users manage their daily finances by tracking income, expenses, and transaction history through a clean and responsive interface.

## Features

- Secure user authentication and authorization
- Add, edit, and delete income/expense transactions
- Expense categorization for better financial tracking
- Real-time balance and transaction updates
- Responsive user interface built with React and Tailwind CSS
- RESTful API integration using Express.js and Node.js
- MongoDB database integration for persistent storage
- User-friendly dashboard with transaction history

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
